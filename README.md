# Design System of Edgecom Energy

Edgecom Energy's design system docs site **and** the source of truth for the public `edgecom-ai/design-system` shadcn component registry, distributed straight from GitHub.

Docs by audience:

- **Design language & usage rules** (tokens, typography, dark mode, component conventions, accessibility) → **[design.md](design.md)** (published at [design.edgecom.ai/design.md](https://design.edgecom.ai/design.md)).
- **Building an app with the design system** (installing from the registry, composing) → **[AGENTS.md](AGENTS.md)**.
- **Registry install mechanics** — installs are `pnpm dlx shadcn@latest add edgecom-ai/design-system/<name>` → **[REGISTRY.md](REGISTRY.md)**.
- **Developing this repo** (authoring primitives, tokens, the docs site) → **[MAINTAINERS.md](MAINTAINERS.md)**.
- **Discovery index for agents** → [llms.txt](https://design.edgecom.ai/llms.txt).
